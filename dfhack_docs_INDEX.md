DFHack's own manual, as DFHack ships it in Dwarf Fortress's `hack/docs/` folder: every page rendered as plain text. It is the Lua API reference, the guides, the changelogs and one page per tool. The newest entry in its changelog is DFHack 53.16-r2. It is DFHack's account of what DFHack does: the code is the source of truth, and what is measured in game outranks it.

491 files: 36 pages, 5 changelogs and 450 tool pages.

## How to use this

Paths below are inside `dfhack_docs/`. Every section is given with the line its heading is on, so a section can be read straight off the page. `Lua API.txt` has a space in its name, so quote the path:

```
grep -n 'dfhack.matinfo' 'dfhack_docs/docs/dev/Lua API.txt'
sed -n '785,836p' 'dfhack_docs/docs/dev/Lua API.txt'   # Material info lookup
grep -rln 'reaction_class' dfhack_docs/docs/tools/
```
